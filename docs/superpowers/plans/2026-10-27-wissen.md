# Wissen: Maschine lernt belegte Sätze (Baustein 2) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Jede Maschine hat ein Gedächtnis aus belegten Sätzen, das der Agent bei jeder Antwort mitliest, nach jedem Lauf und jeder Chat-Antwort ergänzt und das Sinan im Tab „Wissen“ sieht, sperrt, korrigiert und löscht.

**Architecture:** Tabelle `machine_notes` (Alembic 0007). Reine Logik in `app/wissen/lernen.py` (Prompt, Parsen, Beleg-Pflicht, Dubletten, Prompt-Block) und `app/wissen/obsidian.py` (Markdown je Maschine). `app/wissen/dienst.py` bündelt Datenbank, Modellaufruf und Obsidian-Datei. Neuer Schritt „Lernen“ (Nr. 7 von 8) im Ablauf, Hintergrund-Thread nach jeder Chat-Antwort mit Quellen. `system_prompt_for` hängt den Block „Bisher über diese Maschine gelernt“ an. Router `app/api/wissen.py`, Tab „Wissen“ unter „Mehr“ auf der Maschinenseite.

**Tech Stack:** FastAPI, SQLAlchemy 2, Alembic, LangChain `make_chat_model`, Next.js 16, Vitest, Playwright. Keine neuen Abhängigkeiten.

**Spec:** `docs/superpowers/specs/2026-10-26-ablauf-wissen-vergleich-design.md`, Abschnitt „Baustein 2: Wissen“.

## Global Constraints

- Repo-Regeln `AGENTS.md`, `frontend/AGENTS.md` (Next.js 16: `node_modules/next/dist/docs/` lesen). Ponytail: nur, was die Spec nennt.
- Höchstens 5 Sätze je Lauf, höchstens 2 je Chat-Antwort, höchstens 30 Sätze im Prompt (gesperrte zuerst, dann neueste). Nur Sätze mit mindestens einem gültigen Beleg werden gespeichert. Dubletten über normalisierten Text (Kleinschreibung, Leerraum zusammengezogen, Satzzeichen am Ende weg).
- `quelle` ist eins von `lauf`, `chat`, `mensch`. PATCH setzt `gesperrt=true` und `quelle="mensch"`. Gesperrte Sätze werden nie automatisch überschrieben oder entfernt.
- Beleg = `{"document_id": str, "page": int | None}`; `document_id` muss zu einem Dokument der Wissensquelle der Maschine gehören.
- Prompt-Block in `<kontext>…</kontext>`, nach dem Maschinenkontext (Anfang bleibt cachebar). `PROMPT_VERSION = 5`.
- Obsidian: `DATA_DIR/wissen/<dateiname>.md`, Frontmatter `machine_id`, `stand` (ISO, UTC), je Satz eine Zeile. Dateiname nur `A-Za-z0-9äöüÄÖÜß ._-`, sonst `_`; leer → `machine_id`. Kein Sync in fremde Repos.
- Fehler beim Lernen nach einer Chat-Antwort sind still (Log), nie Teil der Antwort; im Demo-Modus (`DEMO_MODE`) lernt der Chat nicht. Der Lern-Schritt im Ablauf scheitert nur, wenn das Modell nicht erreichbar ist; „0 Sätze gelernt“ ist ein fertiger Schritt.
- Kosten über `ledger.record_usage` mit Zweck `wissen.lernen`; Langfuse-Tags `wissen` plus `lauf` bzw. `chat`.
- Öffentliche Texte: keine Kosten, keine Projekt-IDs, keine Zitate von Personen. Farben nur Tokens, Ziele ≥ 44 px, `aria-label` an Icon-Knöpfen.
